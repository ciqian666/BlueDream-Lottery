<h1 align="center">BlueDream-Lottery</h1>

<h3 align="center">高自由度抽奖插件 · 全 GUI 可视化编辑</h3>

<p align="center"><b>支持 1.20.x ~ 26.x ｜ 原生 Folia 兼容</b></p>

<p align="center">集抽奖动画、保底机制、指令奖励、物理抽奖方块、排行榜统计于一体的全功能抽奖系统，为服务器打造极致的抽奖体验。</p>

---

## ◆ 插件特色 ◆

**▍ 抽奖体验**

- **视觉盛宴** —— 内置 18 种不同风格的抽奖动画，支持为每个奖池独立配置
- **抽奖模式** —— 支持 **左键单抽** 与 **右键十连抽**，自动计算消耗，体验丝般顺滑
- **保底系统** —— 支持设置「超级大奖」与保底次数，运气不佳时保底机制确保奖励按时降临
- **指令奖励** —— 奖池物品不仅发放道具，还支持配置多条后台指令（发金币、点券、权限组等），支持 PlaceholderAPI 变量
- **沉浸音效** —— 所有抽奖动画均有音效反馈，每一次抽奖都充满仪式感

**▍ 支付与入口**

- **多种支付** —— 完美兼容 Vault（金币）、PlayerPoints（点券）以及自定义钥匙物品
- **物理入口** —— 支持物理抽奖方块，可将地图任意方块设为抽奖入口，支持防破坏与防爆炸保护
- **便携宝箱** —— 管理员可发放特定奖池的宝箱物品，玩家右键直接开启抽奖

**▍ 展示与公告**

- **全息展示** —— 抽奖方块上方自动悬浮 3D 物品模型与奖池名称，支持自动轮播展示奖池物品
- **广播公告** —— 支持全服广播玩家中奖信息，超级大奖更有特殊公告提示

**▍ 管理与数据**

- **全 GUI 编辑** —— 无需频繁改配置，游戏内即可完成所有奖池设置、概率调整与动画切换，支持权重/概率可视化编辑
- **统计系统** —— 内置完善抽奖统计，支持 SQLite / MySQL / MariaDB / PostgreSQL 数据库，记录全服抽奖数据
- **排行榜** —— 支持抽奖次数榜、消费榜、超级大奖榜、欧皇榜，GUI 可视化展示
- **国际化** —— 支持 zh_cn / en_us 语言动态切换，自定义消息提示

**▍ 性能与兼容**

- **极速性能** —— 玩家独立数据文件 + 异步快照保存机制，彻底告别保存卡顿
- **贴心防护** —— 背包满了自动将奖品掉落在玩家脚下并发出温馨提示
- **全版本 + Folia** —— 1.20.x 到 26.x 全版本适配，并原生支持 Folia 服务端

## ◆ 抽奖动画 ◆

内置 **18 种** 风格各异的抽奖动画，从经典的 **老虎机**、**幸运转盘**、**颜色风暴**，到炫酷的 **悬浮**、**黑洞吞噬**、**螺旋基因**、**次元解构** 等 3D 动画，每一个奖池都可以独立配置专属动画，打造独一无二的抽奖体验。

## ◆ 多种支付方式 ◆

| 支付方式 | 说明 |
| --- | --- |
| **免费** | 只需消耗宝箱即可开启 |
| **金币** | 接入 Vault，消耗服务器经济货币 |
| **点券** | 接入 PlayerPoints，消耗点券积分 |
| **钥匙** | 自定义钥匙物品，可由任意物品充当 |

## ◆ 全 GUI 可视化编辑 ◆

无需频繁修改配置文件，游戏内通过图形界面即可完成奖池的全部配置：

- **花费设置**：一键切换 免费 / 金币 / 点券 / 钥匙 四种支付方式，点击即可修改花费数值
- **钥匙物品**：**Shift + 左键** 点击背包任意物品，即可将其设为该奖池的抽奖钥匙
- **动画切换**：左键切换下一个动画、右键切换上一个，实时预览效果
- **保底次数**：左键手动输入精确数值，右键快速 +10
- **奖池宝箱**：自定义宝箱材质与名称，一键发放到背包
- **消耗模式**：随时切换抽奖时是否消耗宝箱物品
- **概率显示**：开关抽奖界面中的掉落概率提示
- **物品管理**：可视化编辑每件物品的权重/概率，一键标记超级大奖、配置指令奖励、开关聊天栏公告

## ◆ 粒子特效 ◆

抽奖方块支持 **5 种** 环绕粒子特效，管理员 GUI 一键切换并自动保存：

- **绚丽双螺旋**：双螺旋上升的龙息与末地烛粒子
- **神圣光环**：动态起伏的彩色音符与神圣光效
- **璀璨星尘**：从顶部飘落的彩色附魔文字
- **烈焰之环**：交错旋转的火焰与烟雾
- **奥术灵气**：地面升腾的紫色魔法符文

粒子仅在玩家 **32 格** 范围内渲染，最大限度降低服务器负担。

## ◆ 统计与排行榜 ◆

内置完善的抽奖统计系统，记录全服抽奖流水：

- **多引擎数据库**：支持 SQLite / MySQL / MariaDB / PostgreSQL，HikariCP 连接池统一管理
- **四大排行榜**：抽奖次数榜、消费榜、超级大奖榜、欧皇榜（基于真实爆率算法）
- **热门分析**：统计最受欢迎的奖池 TOP5 与掉落频率最高的物品
- **系统监控**：实时查看数据库连接状态与配置信息
- **异步引擎**：统计计算与日志记录均在独立线程完成，TPS 零损耗

## ◆ 命令与权限 ◆

| 命令 | 描述 | 权限 |
| --- | --- | --- |
| `/lt help` | 查看完整帮助 | — |
| `/lt create <奖池名>` | 创建新奖池并打开编辑器 | `bluedream.lottery.admin` |
| `/lt remove <奖池名>` | 删除指定奖池 | `bluedream.lottery.admin` |
| `/lt rename <旧名> <新名>` | 重命名奖池 | `bluedream.lottery.admin` |
| `/lt edit <奖池名>` | 打开图形化编辑器 | `bluedream.lottery.admin` |
| `/lt setblock <奖池名>` | 将准星方块设为抽奖入口 | `bluedream.lottery.admin` |
| `/lt removeblock` | 移除准星方块的抽奖设置 | `bluedream.lottery.admin` |
| `/lt play <奖池名> [次数]` | 打开抽奖界面（可指定次数） | `bluedream.lottery.use`（玩家默认拥有） |
| `/lt give <奖池> <数量> [玩家]` | 给予抽奖箱 | `bluedream.lottery.admin` |
| `/lt stats` | 查看统计与排行榜 | `bluedream.lottery.use` |
| `/lt ranking <类型>` | 查看指定类型排行榜 | `bluedream.lottery.use` |
| `/lt cleanup` | 清理残留全息图 | `bluedream.lottery.admin` |
| `/lt lang <zh_cn\|en_us>` | 切换语言 | `bluedream.lottery.admin` |
| `/lt reload` | 重载配置文件 | `bluedream.lottery.admin` |

## ◆ 安装与依赖 ◆

1. 下载 **BlueDream-Lottery.jar** 并放入服务器 `plugins` 文件夹
2. 重启服务器，插件自动生成配置文件
3. （可选）安装以下前置插件以获得完整体验：

| 前置插件 | 用途 |
| --- | --- |
| Vault | 金币支付 |
| PlayerPoints | 点券支付 |
| PlaceholderAPI | 指令奖励变量 / 占位符 |

**▍ PlaceholderAPI 变量**

| 变量 | 说明 |
| --- | --- |
| `%bluedream_pity_<奖池名>%` | 玩家在该奖池当前已累计的保底次数 |
| `%bluedream_max_pity_<奖池名>%` | 该奖池设定的触发保底所需次数 |
| `%bluedream_total_draws_<奖池名>%` | 玩家在该奖池累计抽奖总次数 |
| `%bluedream_total_draws%` | 玩家全服累计抽奖总数 |
