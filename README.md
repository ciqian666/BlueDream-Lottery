<h1 align="center" style="color:#1b6ec2">BlueDream-Lottery</h1>

<h3 align="center" style="color:#34495e">高自由度抽奖插件 · 全 GUI 可视化编辑</h3>

<p align="center"><span style="color:#e67e22"><strong>支持 1.20.x ~ 26.x ｜ 原生 Folia 兼容</strong></span></p>

<p align="center"><span style="color:#7f8c8d">集抽奖动画、保底机制、指令奖励、物理抽奖方块、排行榜统计于一体的全功能抽奖系统，为服务器打造极致的抽奖体验。</span></p>

<p align="center"><span style="color:#bdc3c7">━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━</span></p>

<h2 align="center" style="color:#1b6ec2">━━━━━ ◆ 插件特色 ◆ ━━━━━</h2>

<p><span style="color:#e67e22"><strong>▍ 抽奖体验</strong></span></p>

- <span style="color:#e67e22"><strong>视觉盛宴</strong></span> —— 内置 <strong>18 种</strong>不同风格的抽奖动画，支持为每个奖池独立配置
- <span style="color:#e67e22"><strong>抽奖模式</strong></span> —— 支持 <strong>左键单抽</strong> 与 <strong>右键十连抽</strong>，自动计算消耗，体验丝般顺滑
- <span style="color:#e67e22"><strong>保底系统</strong></span> —— 支持设置「超级大奖」与保底次数，运气不佳时保底机制确保奖励按时降临
- <span style="color:#e67e22"><strong>指令奖励</strong></span> —— 奖池物品不仅发放道具，还支持配置多条后台指令（发金币、点券、权限组等），支持 PlaceholderAPI 变量
- <span style="color:#e67e22"><strong>沉浸音效</strong></span> —— 所有抽奖动画均有音效反馈，每一次抽奖都充满仪式感

<p><span style="color:#2980b9"><strong>▍ 支付与入口</strong></span></p>

- <span style="color:#2980b9"><strong>多种支付</strong></span> —— 完美兼容 Vault（金币）、PlayerPoints（点券）以及自定义钥匙物品
- <span style="color:#2980b9"><strong>物理入口</strong></span> —— 支持物理抽奖方块，可将地图任意方块设为抽奖入口，支持防破坏与防爆炸保护
- <span style="color:#2980b9"><strong>便携宝箱</strong></span> —— 管理员可发放特定奖池的宝箱物品，玩家右键直接开启抽奖

<p><span style="color:#8e44ad"><strong>▍ 展示与公告</strong></span></p>

- <span style="color:#8e44ad"><strong>全息展示</strong></span> —— 抽奖方块上方自动悬浮 3D 物品模型与奖池名称，支持自动轮播展示奖池物品
- <span style="color:#8e44ad"><strong>广播公告</strong></span> —— 支持全服广播玩家中奖信息，超级大奖更有特殊公告提示

<p><span style="color:#27ae60"><strong>▍ 管理与数据</strong></span></p>

- <span style="color:#27ae60"><strong>全 GUI 编辑</strong></span> —— 无需频繁改配置，游戏内即可完成所有奖池设置、概率调整与动画切换，支持权重/概率可视化编辑
- <span style="color:#27ae60"><strong>统计系统</strong></span> —— 内置完善抽奖统计，支持 SQLite / MySQL / MariaDB / PostgreSQL 数据库，记录全服抽奖数据
- <span style="color:#27ae60"><strong>排行榜</strong></span> —— 支持抽奖次数榜、消费榜、超级大奖榜、欧皇榜，GUI 可视化展示
- <span style="color:#27ae60"><strong>国际化</strong></span> —— 支持 zh_cn / en_us 语言动态切换，自定义消息提示

<p><span style="color:#c0392b"><strong>▍ 性能与兼容</strong></span></p>

- <span style="color:#c0392b"><strong>极速性能</strong></span> —— 玩家独立数据文件 + 异步快照保存机制，彻底告别保存卡顿
- <span style="color:#c0392b"><strong>贴心防护</strong></span> —— 背包满了自动将奖品掉落在玩家脚下并发出温馨提示
- <span style="color:#c0392b"><strong>全版本 + Folia</strong></span> —— 1.20.x 到 26.x 全版本适配，并原生支持 Folia 服务端

<p align="center"><span style="color:#bdc3c7">━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━</span></p>

<h2 align="center" style="color:#1b6ec2">━━━━━ ◆ 抽奖动画 ◆ ━━━━━</h2>

内置 <strong style="color:#e67e22">18 种</strong>风格各异的抽奖动画，从经典的 <strong>老虎机</strong>、<strong>幸运转盘</strong>、<strong>颜色风暴</strong>，到炫酷的 <strong>悬浮</strong>、<strong>黑洞吞噬</strong>、<strong>螺旋基因</strong>、<strong>次元解构</strong> 等 3D 动画，每一个奖池都可以独立配置专属动画，打造独一无二的抽奖体验。

<p align="center"><span style="color:#bdc3c7">━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━</span></p>

<h2 align="center" style="color:#1b6ec2">━━━━━ ◆ 多种支付方式 ◆ ━━━━━</h2>

| <strong>支付方式</strong> | <strong>说明</strong> |
| --- | --- |
| <span style="color:#27ae60"><strong>免费</strong></span> | 只需消耗宝箱即可开启 |
| <span style="color:#e67e22"><strong>金币</strong></span> | 接入 Vault，消耗服务器经济货币 |
| <span style="color:#2980b9"><strong>点券</strong></span> | 接入 PlayerPoints，消耗点券积分 |
| <span style="color:#8e44ad"><strong>钥匙</strong></span> | 自定义钥匙物品，可由任意物品充当 |

<p align="center"><span style="color:#bdc3c7">━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━</span></p>

<h2 align="center" style="color:#1b6ec2">━━━━━ ◆ 全 GUI 可视化编辑 ◆ ━━━━━</h2>

无需频繁修改配置文件，游戏内通过图形界面即可完成奖池的全部配置：

- <strong>花费设置</strong>：一键切换 免费 / 金币 / 点券 / 钥匙 四种支付方式，点击即可修改花费数值
- <strong>钥匙物品</strong>：<strong>Shift + 左键</strong> 点击背包任意物品，即可将其设为该奖池的抽奖钥匙
- <strong>动画切换</strong>：左键切换下一个动画、右键切换上一个，实时预览效果
- <strong>保底次数</strong>：左键手动输入精确数值，右键快速 +10
- <strong>奖池宝箱</strong>：自定义宝箱材质与名称，一键发放到背包
- <strong>消耗模式</strong>：随时切换抽奖时是否消耗宝箱物品
- <strong>概率显示</strong>：开关抽奖界面中的掉落概率提示
- <strong>物品管理</strong>：可视化编辑每件物品的权重/概率，一键标记超级大奖、配置指令奖励、开关聊天栏公告

<p align="center"><span style="color:#bdc3c7">━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━</span></p>

<h2 align="center" style="color:#1b6ec2">━━━━━ ◆ 粒子特效 ◆ ━━━━━</h2>

抽奖方块支持 <strong style="color:#e67e22">5 种</strong>环绕粒子特效，管理员 GUI 一键切换并自动保存：

- <span style="color:#8e44ad"><strong>绚丽双螺旋</strong></span>：双螺旋上升的龙息与末地烛粒子
- <span style="color:#f39c12"><strong>神圣光环</strong></span>：动态起伏的彩色音符与神圣光效
- <span style="color:#2980b9"><strong>璀璨星尘</strong></span>：从顶部飘落的彩色附魔文字
- <span style="color:#c0392b"><strong>烈焰之环</strong></span>：交错旋转的火焰与烟雾
- <span style="color:#27ae60"><strong>奥术灵气</strong></span>：地面升腾的紫色魔法符文

粒子仅在玩家 <strong>32 格</strong>范围内渲染，最大限度降低服务器负担。

<p align="center"><span style="color:#bdc3c7">━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━</span></p>

<h2 align="center" style="color:#1b6ec2">━━━━━ ◆ 统计与排行榜 ◆ ━━━━━</h2>

内置完善的抽奖统计系统，记录全服抽奖流水：

- <strong>多引擎数据库</strong>：支持 SQLite / MySQL / MariaDB / PostgreSQL，HikariCP 连接池统一管理
- <strong>四大排行榜</strong>：抽奖次数榜、消费榜、超级大奖榜、欧皇榜（基于真实爆率算法）
- <strong>热门分析</strong>：统计最受欢迎的奖池 TOP5 与掉落频率最高的物品
- <strong>系统监控</strong>：实时查看数据库连接状态与配置信息
- <strong>异步引擎</strong>：统计计算与日志记录均在独立线程完成，TPS 零损耗

<h2 align="center" style="color:#1b6ec2">━━━━━ ◆ 命令与权限 ◆ ━━━━━</h2>

| <strong>命令</strong> | <strong>描述</strong> | <strong>权限</strong> |
| --- | --- | --- |
| `/lt help` | 查看完整帮助 | — |
| `/lt create <奖池名>` | 创建新奖池并打开编辑器 | <span style="color:#c0392b">`bluedream.lottery.admin`</span> |
| `/lt remove <奖池名>` | 删除指定奖池 | <span style="color:#c0392b">`bluedream.lottery.admin`</span> |
| `/lt rename <旧名> <新名>` | 重命名奖池 | <span style="color:#c0392b">`bluedream.lottery.admin`</span> |
| `/lt edit <奖池名>` | 打开图形化编辑器 | <span style="color:#c0392b">`bluedream.lottery.admin`</span> |
| `/lt setblock <奖池名>` | 将准星方块设为抽奖入口 | <span style="color:#c0392b">`bluedream.lottery.admin`</span> |
| `/lt removeblock` | 移除准星方块的抽奖设置 | <span style="color:#c0392b">`bluedream.lottery.admin`</span> |
| `/lt play <奖池名> [次数]` | 打开抽奖界面（可指定次数） | <span style="color:#27ae60">`bluedream.lottery.use`</span>（玩家默认拥有） |
| `/lt give <奖池> <数量> [玩家]` | 给予抽奖箱 | <span style="color:#c0392b">`bluedream.lottery.admin`</span> |
| `/lt stats` | 查看统计与排行榜 | <span style="color:#27ae60">`bluedream.lottery.use`</span> |
| `/lt ranking <类型>` | 查看指定类型排行榜 | <span style="color:#27ae60">`bluedream.lottery.use`</span> |
| `/lt cleanup` | 清理残留全息图 | <span style="color:#c0392b">`bluedream.lottery.admin`</span> |
| `/lt lang <zh_cn\|en_us>` | 切换语言 | <span style="color:#c0392b">`bluedream.lottery.admin`</span> |
| `/lt reload` | 重载配置文件 | <span style="color:#c0392b">`bluedream.lottery.admin`</span> |

<h2 align="center" style="color:#1b6ec2">━━━━━ ◆ 安装与依赖 ◆ ━━━━━</h2>

1. 下载 <strong>BlueDream-Lottery.jar</strong> 并放入服务器 `plugins` 文件夹
2. 重启服务器，插件自动生成配置文件
3. （可选）安装以下前置插件以获得完整体验：

| <strong>前置插件</strong> | <strong>用途</strong> |
| --- | --- |
| Vault | 金币支付 |
| PlayerPoints | 点券支付 |
| PlaceholderAPI | 指令奖励变量 / 占位符 |

<p><span style="color:#1b6ec2"><strong>▍ PlaceholderAPI 变量</strong></span></p>

| <strong>变量</strong> | <strong>说明</strong> |
| --- | --- |
| `%bluedream_pity_<奖池名>%` | 玩家在该奖池当前已累计的保底次数 |
| `%bluedream_max_pity_<奖池名>%` | 该奖池设定的触发保底所需次数 |
| `%bluedream_total_draws_<奖池名>%` | 玩家在该奖池累计抽奖总次数 |
| `%bluedream_total_draws%` | 玩家全服累计抽奖总数 |
